# Asgar Luxury Bags Website

## Files
- index.html — complete website UI
- app.js — mobile menu, bulk quote modal and WhatsApp inquiry workflow

## Upload
Upload both files to your hosting/Vercel project:
1. index.html
2. app.js

Keep them in the same folder.
